# Sanitisation and security policy

This showcase contains public demonstrations only.

## Included

- Synthetic order numbers, products, customer events and operational metrics.
- Browser-only interactions that do not connect to production services.
- Simplified patterns already described publicly on the Drabyna portfolio.

## Excluded

- Production credentials, tokens, environment values and API keys.
- Customer records, customer email content, images or order histories.
- Private repository files, commit history or implementation details.
- Production hostnames, database schemas, internal identifiers or live endpoints.

## Reporting

If you believe sensitive information has been published here, email `projects@drabyna.com` with the repository path and a short description. Do not include private credentials in the report.
